## Description

Build the onboarding step requiring the account holder to affirmatively attest they are the parent/legal guardian of the monitored device's user (or have obtained consent) before a pairing session can be created.

**Critical design requirement:** This is a **server-side hard gate**, not just a UI checkbox. No code path exists to create a pairing session without a completed attestation.

---

## Acceptance Criteria

- [x] Attestation is a hard prerequisite the pairing API enforces server-side — not just a UI checkbox

### API Endpoints

#### `POST /api/v1/attestations`
Creates a guardian attestation record.

**Request:**
```json
{
  "account_id": "uuid",
  "attestation_text": "I affirm that I am the parent or legal guardian of the minor whose device will be monitored, or I have obtained explicit consent from the device owner."
}
```

**Response (201 Created):**
```json
{
  "id": "uuid",
  "account_id": "uuid",
  "attestation_timestamp": "2026-09-13T12:00:00Z"
}
```

**Storage:** Attestation record includes:
- Immutable ID
- Account ID
- Attestation text (full disclosure)
- Timestamp (UTC)
- IP address (captured automatically)
- User agent (captured automatically)

#### `GET /api/v1/attestations/account/{accountId}`
Retrieves attestation history for an account (audit purposes).

### Server-Side Enforcement

In `PairingController.CreatePairingSession()`:

```csharp
// VE-002: Hard gate — no pairing without completed attestation
var account = await _db.Accounts
    .Where(a => a.Id == accountId)
    .Select(a => new { a.CompletedAttestationId })
    .FirstOrDefaultAsync();

if (!account.CompletedAttestationId.HasValue)
{
    _logger.LogWarning(
        "VE-002: Pairing session blocked for account {AccountId} — no completed attestation",
        accountId);
    return BadRequest(new {
        error = "guardian_attestation_required",
        message = "Guardian consent attestation must be completed before device pairing"
    });
}
```

**No bypass paths exist:** The pairing API checks `CompletedAttestationId` before creating any `PairingSession`.
